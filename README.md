# ECF Projet - Authentification

## Description
Application web avec système d'authentification utilisant Supabase.

## Installation
1. Cloner le repository
2. Installer les dépendances : `npm install`
3. Configurer Supabase dans `config/supabase.js`
4. Lancer le serveur : `node app.js`

## Fonctionnalités
- ✅ Inscription utilisateur
- ✅ Connexion utilisateur
- ✅ Interface responsive
- ✅ Intégration Supabase

## Technologies
- Node.js
- Express.js
- Supabase
- HTML/CSS/JavaScript
